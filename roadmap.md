# 🚀 ChatGPT Exporter: Goated Roadmap

This roadmap outlines the evolution from a simple ChatGPT tool to a universal **Universal AI Insight Hub**.

## 📍 Phase 1: Foundation & "ChatGPT Goated" (Current)
- [x] Background Export Processing
- [x] Manifest V3 Compliance (Fixed CSP errors)
- [x] Selection Export (Floating Snippet Button)
- [x] Insight Dashboard with Analytics
- [x] Workspace/Project Filtering
- [x] Deep Search with Highlighting
- [x] Activity Heatmaps

## 🛣 Phase 2: Multi-Platform Expansion (Up Next)
- [ ] **Multi-AI Support**: Logic to detect and scrape alternate LLM interfaces.
  - [ ] **Gemini Integration**: Support for `gemini.google.com`.
  - [ ] **Claude Integration**: Support for `claude.ai`.
  - [ ] **Grok/Perplexity/Mistral/Deepseek/Kimi/z.ai**: Unified harvesting logic for leading cloud LLMs.
- [ ] **Unified Dashboard**: Merge history from all platforms into one analytical view.
- [ ] **Brand Identity**: Custom logo, branding, and premium UI kit.

## 🛰 Phase 3: Intelligence & Interop
- [ ] **Automated PDF Reports**: Export "Goated" summaries as stylized PDFs.
- [ ] **Obsidian/Notion Sync**: Direct push to note-taking apps via API.
- [ ] **Topic Modeling**: Use local processing to categorize chats automatically.
- [ ] **Collaborative Sharing**: Share specific snippets via secure quicklinks.

## 🎖 Phase 4: Release & Distribution
- [ ] **Official GitHub Release**: Versioned ZIP downloads and release notes.
- [ ] **Chrome Web Store Submission**: Reach the global audience.
- [ ] **Auto-Updater**: Check for new "Goated" features automatically.
